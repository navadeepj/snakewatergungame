# Snake Water Gun Game 🐍💧🔫

A simple Python command-line game based on the classic Snake, Water, Gun game played in childhood.  
The user plays against the computer, which makes a random choice each round.

## Game Rules
- Snake drinks Water → Snake wins  
- Water disables Gun → Water wins  
- Gun kills Snake → Gun wins  
- Same choice → Draw  

## Features
- User vs Computer gameplay
- Random computer moves using Python's random module
- Input validation for correct choices
- Simple and beginner-friendly logic

## Technologies Used
- Python 3
- Python Standard Library (`random`)

## How to Run
1. Clone or download this repository
2. Open a terminal in the project folder
3. Run the program:
4. Enter your choice: `snake`, `water`, or `gun`

## Purpose
This project is created to practice basic Python concepts such as:
- Conditional statements
- User input handling
- Random number generation
- Simple game logic
